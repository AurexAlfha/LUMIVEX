# LUMIVEX Dataset

LUMIVEX keeps raw, processed, training, and validation data separate.

## Structure

- `raw/` — original source material
- `processed/` — cleaned/combined material
- `master_train.txt` — training corpus
- `master_validation.txt` — validation corpus
- `dataset_manifest.txt` — source and license records

External datasets must be checked for licensing and permitted use before being added.
